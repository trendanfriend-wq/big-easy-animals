# Big Easy Animals — coloring-book videos

Kid-safe animal videos for the Big Easy coloring book QR codes.

Each file is `videos/<animal>_mix.mp4` (854×480, narration + real animal sound + “Well done!” end card).

## Watch a video
`https://trendanfriend-wq.github.io/big-easy-animals/videos/<animal>_mix.mp4`

Example: [https://trendanfriend-wq.github.io/big-easy-animals/videos/bear_mix.mp4](https://trendanfriend-wq.github.io/big-easy-animals/videos/bear_mix.mp4)
